# MetaNode 面试准备文档

## 怎么用

1. **先通读 00 和 05**，这两篇是把整个项目串起来的主干。
2. **按 01→03→02→04 补细节**，每篇都是方法级、带行号，对着源码看一遍。
3. **考前用 06 和 07 突击**，06 是速查表，07 是问答预演。

## 核心一句话（背下来）

> MetaNode 是「链下撮合、链上结算」的永续合约系统：用户 EIP-712 签名订单，relayer 在内存订单簿撮合，只有撮合成功的 `trade()` 才上链；链上 `approveTrade` 重新验签保证 relayer 不可信也安全。
